Installation

      

        

          
HACS (Recommended)

          
    
            
  1. Click the Home Assistant badge above, or open HACS in Home Assistant.
    2. 
            
  2. Open the menu (three dots) → Custom repositories.
    3. 
            
  3. Add https://github.com/firstof9/ha-air-quality-card with category Dashboard / Lovelace.
    4. 
            
  4. Search for Air Quality Card, click Download, and add custom:air-quality-card via the Visual Editor.
    5. 
          

        

        

          
Manual

          
    
            
  1. Download air-quality-card.js from the latest release.
    2. 
            
  2. Copy it to <config>/www/air-quality-card.js.
    3. 
            
  3. Register /local/air-quality-card.js as a JavaScript module under Settings → Dashboards → Resources.
    4. 
          

        

      

    


    

      
Supported Entities & Features

      

        
          
OptionPollutant / MetricNotes

        
        
          
aqi_entityAir Quality IndexOptional. When omitted, a 0–100 score is calculated from configured pollutants.

          
temp_entity, humid_entityTemperature & HumidityShown as climate stats and optional mini-graph-card trend lines.

          
pm1_entity, pm25_entity, pm4_entity, pm10_entityParticulate MatterPM1, PM2.5, PM4, and PM10 in µg/m³ with standard threshold bars.

          
co2_entityCarbon Dioxide (CO₂)PPM thresholds for ventilation guidance.

          
voc_entity, nox_entityVOC & NOxSensirion VOC/NOx Index defaults with per-card *_thresholds & *_baseline overrides.

          
radon_entityRadonAuto-selects bands for pCi/L or Bq/m³ based on unit of measurement.
